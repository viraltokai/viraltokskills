# 轻量分镜表模板

## 分镜表是视频生成的硬门控
没有分镜表不得进入提示词编译环节。分镜表将口播脚本转化为可执行的画面指令。

## 标准字段
| 字段 | 说明 |
|------|------|
| 时间 | 时间段（如 0-3s、3-7s） |
| 画面动作 | 景别+人物动作+道具互动+运镜 |
| 人声口型 | 该时间段对应的口播台词原文 |
| 重点花字 | 画面中出现的文字标注（可选，全片不超过3处） |
| 产品保留点 | 产品在该时间段的出现方式 |

## 15 秒四段式标准结构
| 时间段 | 功能 | 画面要求 |
|--------|------|----------|
| 0-3s | Hook 停滑 | 中近景，表情/动作有张力，第一句话必须抓人 |
| 3-7s | 信任建立 | 近景或道具展示，第一人称经历讲述 |
| 7-12s | 产品证明 | 特写或屏幕展示，核心卖点视觉化 |
| 12-15s | CTA 收束 | 回到中近景，微笑推荐，最后1秒静止 hold |

## 高分目的（每段必须明确）
- 0-3s：让用户停下来（痛点共鸣/数字冲击/反差惊讶/场景代入）
- 3-7s：让用户相信（真实经历/身份背书/使用场景）
- 7-12s：让用户看懂（产品功能可视化/效果对比/数据展示）
- 12-15s：让用户行动（软推荐/引导收藏/明确下一步）

## 画面动作写法
- 必须包含：景别（中近景/近景/特写）+ 人物动作 + 道具 + 运镜
- 示例："中近景，主播表情无奈摇头，手边笔记本显示杂乱表格，固定机位"
- 禁止：只写"主播说话"这种无信息量描述

## 产品出现规则
- 每条视频产品至少清晰出现 3 次
- 7-12s 必须有一次产品特写或屏幕展示
- 虚拟产品（资料/Skill/课程）用手机/平板/电脑屏幕展示

## 花字规则
- 全片花字不超过 3 处
- 花字内容为关键词提炼（如"三类竞品全覆盖""几百块搞定"）
- 花字用警戒色或主题色，不超过两种颜色
- 禁止花字遮挡人物面部

## 多场景切换规则
- 双场景切换时人物服装、发型、妆容必须一致
- 场景切换不超过 2 个（15 秒内）
- 切换点放在时间段边界（3s/7s/12s），不在句中切换
