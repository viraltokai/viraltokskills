# Seedance 导演稿六段式模板

## 结构总览
每条 Seedance 提示词必须按以下六段顺序编写，缺一不可：

```
【角色锚点】年龄 + 脸型骨骼 + 发型 + 服装 + 气质
【场景机位】室内/室外 + 背景描述 + 景别 + 运镜
【动作口型】按时间轴逐段描述动作，台词用 {} 包裹
【产品出现】产品出现时间点 + 展示方式 + 画面位置
【光线质感】光线类型 + 色调 + 画面质感 + 滤镜
【负面约束】禁止项清单
```

## 各段写法规范

### 1. 角色锚点
- 必须包含：年龄、脸型骨骼（防撞脸核心）、发型、服装、气质
- 脸型骨骼描述要具体："圆脸柔和骨骼""方脸硬朗线条""鹅蛋脸精致轮廓"
- 每条视频用不同的脸型骨骼，确保不撞脸
- 示例："24岁东亚女性，圆脸柔和骨骼，齐肩直发，米白色针织衫，邻家女孩气质，淡妆"

### 2. 场景机位
- 场景：具体到空间类型（居家书房/办公室/工厂仓库/咖啡馆）
- 背景：描述背景元素（木质书桌/白板/货架）
- 景别：中近景/近景/特写，按分镜表时间轴变化
- 运镜：固定/缓推/跟随/手持晃动
- 示例："明亮居家书房，木质书桌背景，中近景固定机位，手机直拍质感"

### 3. 动作口型
- 按分镜表时间轴逐段写：0-3s / 3-7s / 7-12s / 12-15s
- 每段包含：表情 + 肢体动作 + 道具互动
- 口播台词必须用英文大括号 `{}` 包裹，确保模型生成口型对齐
- 最后一段必须写"最后1秒静止"或"最后1秒 hold"
- 示例："0-3s：表情无奈摇头，{做外贸最坑的不是没客户}。3-7s：拿起手机轻点屏幕，{我之前踩过这个坑}。"

### 4. 产品出现
- 明确产品首次出现时间点
- 虚拟产品：手机/平板/电脑屏幕显示的具体内容
- 实体产品：手持/摆放/使用的方式
- 特写时间点和画面位置
- 示例："3秒起手机屏幕显示调研资料列表，7-12秒特写三栏结构，12秒后保持可见"

### 5. 光线质感
- 光线：自然光/柔光/硬光/侧光
- 色调：暖白调/冷调/中性
- 质感：手机直拍/电影感/纪录片/UGC真实感
- 滤镜：无滤镜/轻微颗粒/复古
- UGC 带货视频推荐：柔和自然光 + 暖白调 + 轻微手机颗粒 + 无电影滤镜

### 6. 负面约束（必写）
标准负面约束清单，每条都要包含：
- 禁止画面出现文字字幕
- 禁止多余人物入镜
- 禁止产品/屏幕内容变形
- 禁止口型与台词错位
- 禁止画面闪烁或跳切
- 根据产品特性追加：禁止品牌logo错误、禁止服装穿帮等

## 完整示例
```
【角色锚点】24岁东亚女性，圆脸柔和骨骼，齐肩直发，米白色针织衫，邻家女孩气质，淡妆。
【场景机位】明亮居家书房，木质书桌背景，中近景固定机位，手机直拍质感，自然光从左侧入。
【动作口型】0-3s：表情无奈摇头，{做外贸最坑的不是没客户，是连对手是谁都没搞清楚就冲出去}。3-7s：拿起手机轻点屏幕，{我之前踩过这个坑，直到用了这套外贸市场调研技能}。7-12s：手机屏幕特写展示三栏分析，{品牌商、制造商、经销商三类竞品一次扒透，市场格局、定价、渠道全给你理清楚}。12-15s：微笑举手机朝镜头，{准备出海的，先领一份看看}，最后1秒静止。
【产品出现】3秒起手机屏幕显示调研资料列表，7-12秒特写三栏结构（品牌商/制造商/经销商），12秒后手机资料页保持可见。
【光线质感】柔和自然光，暖白调，轻微手机颗粒感，UGC真实感，无电影滤镜。
【负面约束】禁止画面出现文字字幕，禁止多余人物入镜，禁止手机屏幕内容变形，禁止口型与台词错位，禁止画面闪烁或跳切。
```

## 批量生成规则
- V1-V4 的【角色锚点】必须使用不同的脸型骨骼和发型
- 【场景机位】可根据 hook 策略调整（痛点型用居家、反差型用办公室、数字型用白板前、场景型用工厂/实地）
- 【动作口型】根据各条分镜表填写
- 【负面约束】六条标准约束每条都必须完整写入
