# 五段式公式

```text
提示词 = 主体 + 风格 + 时间线 + BGM + 限制
```

## 主体

写清主角或产品、场景、核心事件和全片需要保持一致的特征。使用参考素材时，逐项说明职责：

```text
@图1锁定主角脸、发型与服装，全片生效；不参考背景和文字。
@图2锁定产品外形与材质；不改变比例和结构。
@视频1只参考5—9秒的动作节奏与侧向跟拍；不复制人物、场景、品牌或声音。
@音频1作为完整 BGM，从0秒开始并在结尾收束；对白高于音乐。
```

## 风格

至少写时长、画幅、成片形式、光线或色彩和镜头节奏。避免相互矛盾的摄影要求，例如固定机位与持续高速环绕。

## 时间线

每段采用以下格式：

```text
【开始—结束秒】起始状态；可见动作；一个主运镜；结束状态。
```

15 秒默认节奏：`0—2` 建立主体，`2—5` 第一动作，`5—9` 推进，`9—12` 高潮，`12—15` 结果与稳定收尾。动作必须可拍摄，避免用抽象形容词代替动作。

## BGM

写音乐类型、速度或 BPM、核心乐器、情绪变化、关键节拍和结尾方式。对白写说话人、语言、原文、时间、情绪和口型同步；音效只保留关键动作声。

## 限制

只保留当前任务最相关的 3-8 项，例如人物稳定、产品结构、物理关系、文字品牌和声音层级。先解决正文矛盾，再使用限制约束风险。
